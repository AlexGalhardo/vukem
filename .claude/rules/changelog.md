# Changelog rules

- `CHANGELOG.md` follows Keep a Changelog 1.1.0 and is generated by `task changelog` (git-cliff).
- Never edit released sections by hand; fix the commit history or `cliff.toml` instead.
- Sections: Added, Changed, Deprecated, Removed, Fixed, Security. `[Unreleased]` always exists.
- Versions follow SemVer with Go tags `vX.Y.Z`; never move or delete a pushed tag (use `retract`).
