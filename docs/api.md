# REST APIs

Lumek is equally a framework for **JSON/REST APIs** and for server-rendered apps. An API-only project (`lumek new shop --api`) has no views, sessions or CSRF, and ships token auth, JSON errors, pagination, rate limiting and CORS. Decision `H6` in [brainstorming.md](brainstorming.md).

## Starter

```sh
lumek new shop --api        # JSON-only skeleton (no views, no htmx, no session/CSRF stack)
lumek install:api           # add an API route group to an existing web app
```

API skeleton differences from the web starter:

| Area | Web starter | API starter |
| --- | --- | --- |
| Routes | `routes/web.go` | `routes/api.go` (prefix `/api/v1`) |
| Middleware (router stack) | session, CSRF, flash | request id, JSON body limit, CORS, rate limit |
| Auth guard | `session` | `access_token` (ALPHA) |
| Errors | HTML / 422 fragment | `application/problem+json` |
| Extra folders | `resources/views`, `public` | `app/resources` (transformers) |

A web app can have both: `routes/web.go` and `routes/api.go`, each group with its own middleware stack.

## Routing

```go
func API(r *router.Router, app *lumek.App) {
	r.Group("/api/v1", func(g *router.Group) {
		g.Use(api.JSONOnly(), cors.Middleware(app.Config.CORS), ratelimit.Middleware("api"))

		g.Post("/tokens", auth.IssueToken).Name("api.tokens.store")

		g.Group("", func(p *router.Group) {
			p.Use(auth.Required("api"))
			p.APIResource("products", controllers.NewProduct(app)) // index, store, show, update, destroy
			p.APIResource("products.reviews", controllers.NewReview(app)).Shallow()
		})
	}).Name("api.v1.")
}
```

- `APIResource` registers only JSON actions (no `create`/`edit` form routes).
- Nested resources: `"products.reviews"` → `/products/{product}/reviews`; `.Shallow()` puts `show/update/destroy` at `/reviews/{review}`.
- `PUT` and `PATCH` both map to `Update`; `HEAD` is answered for every `GET`; `OPTIONS` handled by CORS.

## Requests

- `web.Bind[T](c)` decodes `application/json` (rejects unknown fields by default; configurable), runs validation, and on failure returns `422` problem+json.
- Body size limited per group (`api.JSONOnly(api.MaxBody(1 << 20))`); oversize → `413`.
- `api.JSONOnly()` rejects non-JSON bodies on write methods with `415` and sets `Accept` negotiation to JSON.
- Query helpers: `c.QueryInt`, `c.QueryBool`, `c.QueryTime`, `c.QuerySlice`.

## Responses

```go
func (p *ProductController) Show(c *web.Ctx) error {
	product, err := orm.Query[models.Product](p.db).Find(c.Context(), c.ParamInt64("product"))
	if err != nil {
		return err // ErrNoRows → 404 problem+json
	}
	return c.JSON(http.StatusOK, resources.Product(product))
}

func (p *ProductController) Store(c *web.Ctx) error {
	in, err := web.Bind[requests.StoreProduct](c)
	if err != nil { return err }
	product := models.Product{Name: in.Name, Price: in.Price}
	if err := orm.Create(c.Context(), p.db, &product); err != nil { return err }
	return c.Created(c.URLFor("api.v1.products.show", "product", product.ID), resources.Product(product)) // 201 + Location
}
```

| Helper | Status | Notes |
| --- | --- | --- |
| `c.JSON(status, v)` | any | `encoding/json` (json/v2 under Go 1.27) |
| `c.Created(location, v)` | 201 | sets `Location` |
| `c.Accepted(v)` | 202 | async work |
| `c.NoContent()` | 204 | |
| `c.Problem(status, title, detail)` | 4xx/5xx | RFC 9457 |

### Resources (transformers)

Separate the wire format from models (Laravel API Resources / AdonisJS v7 Transformers):

```go
// app/resources/product.go — generated by `lumek make:resource Product`
type ProductJSON struct {
	ID        int64     `json:"id"`
	Name      string    `json:"name"`
	Price     string    `json:"price"`
	Reviews   []ReviewJSON `json:"reviews,omitzero"` // only when eager-loaded
	CreatedAt time.Time `json:"created_at"`
}

func Product(p models.Product) ProductJSON { ... }
func Products(ps []models.Product) []ProductJSON { return api.Map(ps, Product) }
```

Plain functions and structs: typed, testable, no reflection. Relations are included only when loaded (strict mode guarantees no hidden queries).

### Envelopes

Default: **no envelope** for single resources; collections and pages use:

```json
{
  "data": [ { "id": 1, "name": "Keyboard" } ],
  "meta": { "page": 1, "per_page": 20, "total": 134, "last_page": 7 },
  "links": { "self": "/api/v1/products?page=1", "next": "/api/v1/products?page=2", "prev": null }
}
```

`api.Page(c, page, Products)` builds it from `orm.Page[T]` (offset) or `orm.CursorPage[T]` (cursor: `meta.next_cursor`). Pagination headers (`Link`, `X-Total-Count`) optional by config.

## Query conventions

Opt-in, allowlisted per endpoint (never free-form columns):

```go
q := api.Query[models.Product](c, orm.Query[models.Product](p.db),
	api.Filters("category", "in_stock"),            // ?filter[category]=books&filter[in_stock]=true
	api.Sorts("name", "price", "-created_at"),     // ?sort=-price,name  (default: last listed)
	api.Includes("reviews"),                       // ?include=reviews → With("Reviews")
	api.Fields("id", "name", "price"),             // ?fields=id,name
	api.PerPage(20, 100),                          // ?page=2&per_page=50 (max 100)
)
page, err := q.Paginate(c.Context())
```

Unknown filter/sort/include → `400` problem+json listing allowed values.

## Errors

All API errors are `application/problem+json` (RFC 9457). The `type` base URI is configurable (`APP_PROBLEM_BASE_URL`) and defaults to `about:blank`:

```json
{
  "type": "about:blank#validation",
  "title": "Validation failed",
  "status": 422,
  "detail": "2 fields are invalid.",
  "instance": "/api/v1/products",
  "request_id": "01JA…",
  "errors": { "name": ["The name field is required."], "price": ["The price must be at least 0."] }
}
```

| Condition | Status |
| --- | --- |
| Malformed JSON / unknown query param | 400 |
| Missing/invalid token | 401 (`WWW-Authenticate: Bearer`) |
| Policy denial | 403 (or 404 with `DenyAsNotFound`) |
| Not found / `ErrNoRows` | 404 |
| Method not allowed | 405 (`Allow` header) |
| Conflict (unique violation, stale `If-Match`) | 409 / 412 |
| Unsupported media type | 415 |
| Validation | 422 |
| Rate limited | 429 (`Retry-After`) |
| Unhandled | 500 (no internals unless debug) |

Database unique-constraint violations are mapped to `409` by the dialect.

## Authentication

- **Access tokens** (opaque, hashed, abilities, expiry) — see [authentication.md](authentication.md#access_token-api). `Authorization: Bearer <token>`.
- `POST /api/v1/tokens` (email + password → token) generated by `install:api`; `DELETE /api/v1/tokens/current` revokes.
- Abilities: `auth.Ability("products:write")` middleware.
- SPA on the same site can use the session guard + `CrossOriginProtection` instead of tokens.
- JWT guard available later behind the same `Guard` interface (post-1.0).

## Cross-cutting

| Concern | Support |
| --- | --- |
| CORS | `cors.Middleware(cfg)`: allowlisted origins, methods, headers, credentials, max-age; deny by default |
| Rate limiting | `ratelimit` per token/user/IP; `RateLimit-*` + `Retry-After` headers |
| Versioning | URL prefix (`/api/v1`) by default; route groups make `/api/v2` side-by-side trivial; deprecation via `Deprecation`/`Sunset` headers helper |
| Caching | `c.ETag(v)` / `If-None-Match` → 304; `Last-Modified`; `Cache-Control` helpers |
| Concurrency control | `If-Match` with ETag → 412 on mismatch |
| Idempotency | `api.Idempotency(store)` middleware for `POST` with `Idempotency-Key` (BETA) |
| Compression | gzip middleware (stdlib `compress/gzip`) |
| Health | `/up`, `/up?checks=1` |
| Request ID | `X-Request-ID` propagated and returned |

## OpenAPI (BETA)

Typed handlers produce an OpenAPI 3.1 document without annotations (Huma/Fuego approach):

```go
api.Register(g, "POST /products", api.Op{
	Name:    "products.store",
	Summary: "Create a product",
	Tags:    []string{"products"},
}, func(c *web.Ctx, in requests.StoreProduct) (resources.ProductJSON, error) { ... })
```

- Request schema from the input struct (`json` + `validate` tags), response schema from the output type, errors from the problem catalogue.
- `GET /openapi.json` (configurable, off in production by default) and `lumek openapi:export > openapi.json`.
- Plain `HandlerFunc` routes still work; they appear in the document with a generic schema unless described with `api.Doc(...)`.

## Testing

```go
app.Test(t).
	WithToken(token).
	PostJSON("/api/v1/products", map[string]any{"name": "Pen", "price": "2.50"}).
	AssertCreated().
	AssertHeader("Location", "/api/v1/products/1").
	AssertJSONPath("name", "Pen")

app.Test(t).GetJSON("/api/v1/products?sort=-price").
	AssertOK().
	AssertJSONCount("data", 20).
	AssertJSONPath("meta.total", 134)

app.Test(t).PostJSON("/api/v1/products", map[string]any{}).
	AssertProblem(422).
	AssertJSONValidationErrors("name", "price")
```

`AssertMatchesOpenAPI()` (BETA) validates the response against the generated document.

## Beyond REST

- **SSE** for server push (BETA) — [frontend.md](frontend.md#sse-beta).
- **GraphQL / gRPC**: not built in. Any `http.Handler` (gqlgen, connect-go, grpc-gateway) mounts on the router and shares middleware, auth and the app container.
