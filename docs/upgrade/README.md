# Upgrade guides

Every minor release (`v1.N.0`) gets a guide in this folder, copied from [TEMPLATE.md](TEMPLATE.md) and named after the version (`1.1.md`). Patch releases do not get guides: they never change the API.

| From | To | Guide |
| --- | --- | --- |
| `v0.x` | `v1.0` | [1.0.md](1.0.md) |

The [stability policy](../stability.md) says what a minor release may and may not change.
