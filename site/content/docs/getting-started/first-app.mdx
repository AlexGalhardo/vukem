Planned for the Prototype release (`v0.1.0`). The CLI, starters, views and ORM used on this page are not implemented yet. Until then, follow [Installation](/docs/installation) to wire the router by hand.
</Callout>

The Prototype goal: a developer installs the CLI, creates an app, and ships a CRUD page with forms, validation, flash messages and HTMX partials on SQLite, plus JSON endpoints for the same data, all covered by tests.

<Steps>
<Step title="Create the project">

```bash
lumek new blog
cd blog
```

</Step>
<Step title="Generate a model, migration and controller">

```bash
lumek make:model Post -m -c
lumek migrate
```

</Step>
<Step title="Register the routes">

```go title="routes/web.go"
func Web(r *router.Router, app *lumek.App) {
	posts := controllers.NewPost(app)

	r.Get("/", home.Index).Name("home")
	r.Resource("posts", posts) // posts.index, posts.create, posts.store…
}
```

</Step>
<Step title="Validate input and redirect">

```go title="app/controllers/post.go"
func (p *PostController) Store(c *web.Ctx) error {
	in, err := web.Bind[requests.StorePost](c) // validates, 422 on failure
	if err != nil {
		return err
	}

	post := models.Post{Title: in.Title, Body: in.Body}
	if err := orm.Create(c.Context(), p.db, &post); err != nil {
		return err
	}

	c.Flash("success", "Post created.")
	return c.RedirectRoute("posts.show", "post", post.ID)
}
```

</Step>
<Step title="Serve it">

```bash
lumek serve   # http://localhost:3000/posts
```

</Step>
</Steps>
