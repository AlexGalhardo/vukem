## An application

`vukem new blog` generates:

```text
blog/
├── cmd/app/main.go            func main() { os.Exit(vukem.Main(bootstrap.New)) }
├── bootstrap/
│   ├── app.go                 New(opts...): providers, migrations, views, routes
│   ├── providers.go           func Providers() []vukem.Provider   (make:provider appends)
│   └── commands.go            func Commands() []vukem.Command     (make:command appends)
├── routes/web.go              func Web(r *router.Router, app *vukem.App) error
├── app/
│   ├── controllers/           Home, PostController
│   ├── models/                Post (orm.Model)
│   └── requests/              input structs and z schemas
├── database/migrations/       timestamped migrations + registry.go (make:migration appends)
├── resources/
│   ├── resources.go           embeds views and public; disk files in development
│   ├── views/                 layouts/, partials/, posts/, home.html
│   └── public/                css/app.css, js/htmx.min.js (htmx 4.0.0, vendored)
├── storage/                   SQLite database and local data (git-ignored)
├── tests/                     home_test.go, posts_test.go (vukemtest)
├── .env.example               copied to .env with a fresh APP_KEY
└── go.mod
```

Everything is wired in code you own: `bootstrap/app.go` lists the providers, migrations, views and routes. Generators edit `bootstrap/providers.go`, `bootstrap/commands.go` and `database/migrations/registry.go` with AST-based codemods; there is no `init()` registration and no reflection-based discovery. If you restructure those files, generators print the line to add by hand instead.

`vukem` keeps its build cache in `.vukem/` and production builds in `bin/`; both are git-ignored.

## The framework

The module `github.com/AlexGalhardo/vukem` is split into small, single-purpose packages. The request context package is named `web` so it never shadows the conventional `ctx context.Context` variable.

| Package | Purpose |
| --- | --- |
| `vukem` (root) | `App`, options, providers, runners, commands, `DefaultMiddleware`, `Main` |
| `config` | `.env` loader, `Load[T]`, `Secret`, `APP_KEY` |
| `router` | ServeMux wrapper: groups, names, resources, URL generation |
| `web` | `*web.Ctx`: input, responses, redirects, rendering, error handler |
| `errs` | `HTTPError`, `ValidationError`, sentinel errors |
| `middleware` | recover, request id, logger, CORS, static, secure headers, gzip… |
| `z` | Zod-style schemas |
| `session`, `csrf` | sessions with flash and old input; cross-origin protection |
| `database`, `orm`, `schema` | SQLite connections, generic query builder, migrations |
| `view`, `htmx` | `html/template` engine; htmx 4 request and response helpers |
| `vukemtest` | in-process test client and database assertions |
| `cmd/vukem` | the CLI |
