## The framework

The module `github.com/AlexGalhardo/golang-framework` is split into small, single-purpose packages. Package names are short, lowercase and singular; the request context package is named `web` so it never shadows the conventional `ctx context.Context` variable.

```text
golang-framework/
├── app.go            package lumek: App, Config, New, options
├── provider.go       Provider, Booter, Shutdowner, KindFilter
├── runner.go         Runner, HTTPServer with safe timeouts
├── config/           .env loader, Load/Fill, Secret, APP_KEY
├── router/           ServeMux wrapper: groups, names, resources, URL generation
├── web/              *web.Ctx: input, responses, redirects, error handler
├── errs/             HTTPError, ValidationError, sentinel errors
├── middleware/       recover, request id, logger, CORS, static, secure headers…
└── internal/         tooling (commit message linter)
```

| Package | Status |
| --- | --- |
| `lumek`, `config`, `router`, `web`, `errs`, `middleware` | Implemented |
| `z`, `session`, `view`, `htmx`, `orm`, `schema`, `database`, `testing`, `cmd/lumek` | Planned for the Prototype release |
| `auth`, `authz`, `social`, `mail`, `cache`, `storage`, `event` | Planned for ALPHA |
| `queue`, `schedule`, `inertia`, `vite`, `i18n`, `sse`, `crypt`, `ratelimit` | Planned for BETA |
| `drivers/postgres`, `drivers/redis`, `drivers/mongo` | Separate modules (ALPHA/BETA) |

## An application

<Callout type="warning">
Planned for the Prototype release. This is the layout `lumek new` will generate.
</Callout>

```text
blog/
├── cmd/app/main.go          signal.NotifyContext + run(ctx, args, getenv, stdout)
├── bootstrap/
│   ├── app.go               lumek.New(...) with providers, routes, middleware
│   ├── providers.go         func Providers() []lumek.Provider (edited by generators)
│   ├── middleware.go        named middleware registry
│   └── commands.go          app commands
├── config/                  typed config structs (app.go, database.go…)
├── routes/
│   ├── web.go               func Web(r *router.Router, app *lumek.App)
│   └── api.go               JSON routes under /api/v1 (--api starter)
├── app/
│   ├── controllers/
│   ├── models/
│   ├── requests/            input structs and z schemas
│   └── resources/           JSON transformers (API starter)
├── migrations/              timestamped migrations + registry.go
├── resources/views/         html/template views, errors/<status>.html
├── public/                  static files served by middleware.Static
├── storage/                 SQLite database, uploads, logs
├── .env.example
└── go.mod
```

Generators write plain Go you own and register it by editing `bootstrap/*.go` with `go/ast` codemods. There is no reflection-based discovery.
