Vukem is a web framework for **REST APIs and full-stack apps**: routing, validation, an ORM with migrations, authentication, JSON resources with problem+json errors, HTMX-first views and an optional Inertia + React frontend, all driven by one CLI.

<Callout type="warning">
Vukem is pre-1.0 and APIs will change between `v0.x` releases. Callouts marked "Planned" describe the design target, not shipped code.
</Callout>

## Why Vukem

- **Standard library first.** Handlers and middleware are plain `net/http`. Any `http.Handler` works.
- **No magic.** No globals, no `init()` registration, no reflection-based dependency injection. Generators write code you own.
- **Typed end to end.** Typed configuration structs, named routes checked at boot, Zod-style schemas (`z`) that parse every input into Go types.
- **Batteries included, opt-in.** SQLite out of the box; PostgreSQL, Redis and MongoDB as separate driver modules, so you only download what you use.
- **APIs first-class.** RFC 9457 problem details, JSON-only route groups, CORS and body limits are built in.
- **Secure by default.** Security headers with CSP nonces, deny-by-default CORS, path-traversal-safe static files and fail-closed boot checks, mapped to the [OWASP Top 10:2025](/docs/security/overview).

## A taste

A handler is a function that receives a `*web.Ctx` and returns an `error`. Returned errors go to a central handler that renders the right response for the client.

```go title="routes.go"
func Routes(r *router.Router, posts *controllers.PostController) {
	r.Get("/", func(c *web.Ctx) error {
		return c.String(http.StatusOK, "Hello from Vukem")
	}).Name("home")

	r.Group("/admin", func(g *router.Group) {
		g.Resource("posts", posts) // posts.index, posts.store, posts.show…
	}).Name("admin.")
}

func (p *PostController) Show(c *web.Ctx) error {
	id, err := c.ParamInt("post") // non-numeric id → 404
	if err != nil {
		return err
	}

	post, ok := p.store.Find(id)
	if !ok {
		return errs.ErrNotFound // HTML page or problem+json, by content negotiation
	}

	return c.JSON(http.StatusOK, post)
}
```

The Prototype (`v0.1`) and ALPHA (`v0.2`–`v0.13`) phases are complete.

| Validation with `z`, sessions, CSRF, `html/template` views, htmx 4 helpers | Available |
| SQLite and [PostgreSQL](/docs/database/overview#postgresql), generic ORM, [relations](/docs/database/relations), migrations, [factories and seeders](/docs/database/factories-seeders) | Available |
| [REST toolkit](/docs/rest-apis/overview): `vukem new --api`, `install:api`, [pagination and query conventions](/docs/rest-apis/pagination), rate limiting, CORS | Available |
| [Authentication](/docs/security/authentication) (session and token guards, `install:auth`), [social login](/docs/security/social-login), [authorization](/docs/security/authorization) | Available |
| [Mail](/docs/digging-deeper/mail) (SMTP, Resend), [cache](/docs/digging-deeper/cache), [storage](/docs/digging-deeper/storage), [events](/docs/digging-deeper/events), [Telegram logging](/docs/digging-deeper/telegram-logging) | Available |
