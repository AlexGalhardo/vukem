## Support matrix

| Database | Package | Phase |
| --- | --- | --- |
| SQLite (pure Go, no cgo) | core, `modernc.org/sqlite` | Prototype |
| PostgreSQL | `drivers/postgres` (pgx) | ALPHA |
| Redis (cache, sessions, queues) | `drivers/redis` | BETA |
| MongoDB | `drivers/mongo` | BETA |

Drivers are separate Go modules, so importing the core never downloads a heavy driver.

## Connections

```go title="config/database.go"
type Database struct {
	Default     string        `env:"DB_CONNECTION"   default:"sqlite"`
	URL         string        `env:"DATABASE_URL"    default:"file:storage/database.sqlite"`
	MaxOpen     int           `env:"DB_MAX_OPEN"     default:"10"`
	MaxIdle     int           `env:"DB_MAX_IDLE"     default:"5"`
	MaxLifetime time.Duration `env:"DB_MAX_LIFETIME" default:"30m"`
}
```

SQLite connections get WAL, `busy_timeout`, foreign keys and a single-writer pool plus a reader pool, so `SQLITE_BUSY` errors are avoided.

## Query builder

Generic, built on `database/sql`, always parameterised. Column names are validated against the model's cached column set, never interpolated from input.

```go
users, err := orm.Query[models.User](db).
	Where("active", true).
	WhereIn("role", []string{"admin", "editor"}).
	OrderBy("created_at", orm.Desc).
	Limit(20).
	Get(ctx) // []models.User

user, err := orm.Query[models.User](db).Find(ctx, 42) // orm.ErrNoRows → 404 in handlers

for u, err := range orm.Query[models.User](db).Each(ctx) { // range-over-func streaming
	if err != nil {
		return err
	}
	process(u)
}
```

## Models

Plain structs; no Active Record. Persistence functions take the executor (`db` or `tx`).

```go
type User struct {
	orm.Model                   // ID, CreatedAt, UpdatedAt
	Name     string
	Email    string `db:"email"`
	Password string `db:"password" json:"-"`
}

err = orm.Create(ctx, db, &user)
err = orm.Update(ctx, db, &user)
err = orm.Delete(ctx, db, &user)
```

## Transactions

```go
err = db.Tx(ctx, func(tx *database.Tx) error {
	if err := orm.Create(ctx, tx, &order); err != nil {
		return err
	}
	return orm.Create(ctx, tx, &item)
}) // commit on nil, rollback on error or panic
```

## Migrations

```go title="migrations/20261016120000_create_users_table.go"
var CreateUsersTable = schema.Migration{
	ID: "20261016120000_create_users_table",
	Up: func(s *schema.Schema) error {
		return s.Create("users", func(t *schema.Table) {
			t.ID()
			t.String("name")
			t.String("email").Unique()
			t.Timestamps()
		})
	},
	Down: func(s *schema.Schema) error { return s.Drop("users") },
}
```

```bash
lumek make:migration create_posts_table
lumek migrate
lumek migrate:status
lumek migrate:rollback
```

Migrations are listed in `migrations/registry.go` (appended by `make:migration`, no `init()` registration) and tracked with checksums. `migrate:fresh` and `db:wipe` require `--force` in production.
