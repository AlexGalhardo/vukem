## Support matrix

| Database | Package | Status |
| --- | --- | --- |
| SQLite (pure Go, no cgo) | core, `modernc.org/sqlite` | Available |
| PostgreSQL | `drivers/postgres` (pgx) | Planned for ALPHA |
| Redis (cache, sessions, queues) | `drivers/redis` | Planned for BETA |
| MongoDB | `drivers/mongo` | Planned for BETA |

Drivers are separate Go modules, so importing the core never downloads a heavy driver. The query builder and migrations already speak both SQLite and PostgreSQL dialects.

## Connecting

`app.DB()` opens the default connection on first use from `DB_*` variables, registers a `db` health check (`/up?checks=1`) and closes it on shutdown:

| Variable | Default |
| --- | --- |
| `DATABASE_URL` | `file:storage/database.sqlite` |
| `DB_MAX_OPEN` | `10` |
| `DB_MAX_IDLE` | `5` |

```go title="routes/web.go"
db, err := app.DB() // *database.DB
if err != nil {
	return err
}
r.Resource("posts", controllers.NewPostController(db))
```

SQLite URLs: `file:storage/app.db`, `sqlite:storage/app.db` or `:memory:`. Other schemes need their driver, added with `lumek.WithDatabaseDrivers(...)`.

Outside an app, `database.Open(ctx, url, database.WithConfig(cfg))` returns the same `*database.DB`; `database.FromSQL(conn, dialect)` wraps an existing `*sql.DB`.

## SQLite defaults

Every SQLite connection gets WAL journaling, `busy_timeout`, `foreign_keys=ON` and `BEGIN IMMEDIATE` for write transactions. Writes and transactions go to a **single-connection writer pool**, reads to a read-only reader pool, so concurrent requests do not fail with `SQLITE_BUSY`.

## Raw SQL

`*database.DB` and `*database.Tx` implement `database.Executor`:

```go
var n int64
err := db.QueryRowContext(ctx, "SELECT COUNT(*) FROM posts WHERE published = ?", true).Scan(&n)
```

Always pass values as arguments; never concatenate input into SQL. `db.Dialect()` gives `Quote` and `Placeholder` for portable statements, and `db.SQL()` exposes the underlying `*sql.DB`.

## Transactions

```go
err := db.Tx(ctx, func(tx *database.Tx) error {
	if err := orm.Create(ctx, tx, &order); err != nil {
		return err
	}

	return orm.Create(ctx, tx, &item)
}) // commit on nil, rollback on error or panic (the panic is re-raised)
```

`database.RunInTx(ctx, ex, fn)` joins the caller's transaction when `ex` is already a `*Tx`, or starts one when it is a `*DB`, which keeps service functions composable.
