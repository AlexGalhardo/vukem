title: HTMX
description: HTMX-first server rendering with request and response helpers, fragments and 422 validation flows.

<Callout type="warning">
Planned for the Prototype release. The `htmx` package and view helpers are not implemented yet. Already available: `c.IsHTMX()`, `HX-Location` redirects, and htmx error fragments from the error handler.
</Callout>

htmx 4 is vendored by the starter at `public/js/htmx.min.js` and served by the static middleware, so **no Node is required**.

## Available today

```go
func (p *PostController) Store(c *web.Ctx) error {
	// …
	if c.IsHTMX() {
		c.SetHeader("HX-Trigger", "post-created")
	}
	return c.Redirect("/posts") // htmx: 200 + HX-Location, browsers: 303
}
```

- `c.IsHTMX()` reports `HX-Request: true`.
- `c.Redirect` answers htmx requests with `HX-Location` (navigation without a full reload), except history-restore requests.
- Errors returned to htmx requests render as an HTML fragment (`<div class="error" role="alert">`) with the real status; htmx 4 swaps 4xx responses by default.

## Request helpers

| Helper | Meaning |
| --- | --- |
| `c.HTMX().Is()` | `HX-Request: true` |
| `c.HTMX().IsPartial()` | `HX-Request-Type: partial`: render a fragment |
| `c.HTMX().IsBoosted()` | `HX-Boosted` |
| `c.HTMX().IsHistoryRestore()` | Must render the full page |
| `c.HTMX().CurrentURL()`, `Source()`, `Target()` | Parsed values |

## Rendering blocks

```go
return c.Render("posts/index", web.Map{"Posts": posts}, htmx.Block("post-list"))
```

`htmx.Block` returns only that block for partial htmx requests and the full page otherwise. `Vary: HX-Request` is always set.

## Response helpers

```go
c.HTMX().Trigger("post-created", web.Map{"id": p.ID}).
	PushURL(c.MustURL("posts.show", "post", p.ID)).
	Retarget("#flash").
	Reswap("innerHTML")
```

Covers `HX-Trigger`, `HX-Location`, `HX-Redirect`, `HX-Refresh`, `HX-Push-Url`, `HX-Replace-Url`, `HX-Retarget`, `HX-Reswap` and `HX-Reselect`.

## Validation flow

An invalid form submitted with htmx re-renders the form block with **422**, errors and old input populated.
