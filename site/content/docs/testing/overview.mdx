Lumek apps are plain Go: handlers are `net/http` handlers and configuration is injected, so the standard `testing` and `net/http/httptest` packages work without any framework support.

## Testing routes today

```go title="routes_test.go"
func TestShowPost(t *testing.T) {
	r := router.New(nil)
	r.Get("/posts/{id}", func(c *web.Ctx) error {
		id, err := c.ParamInt("id")
		if err != nil {
			return err
		}
		return c.JSON(http.StatusOK, web.Map{"id": id})
	})

	h, err := r.Handler()
	if err != nil {
		t.Fatal(err)
	}

	req := httptest.NewRequest(http.MethodGet, "/posts/42", nil)
	rec := httptest.NewRecorder()
	h.ServeHTTP(rec, req)

	if rec.Code != http.StatusOK || rec.Body.String() != `{"id":42}` {
		t.Fatalf("got %d %s", rec.Code, rec.Body)
	}
}
```

## Problem responses

```go
req := httptest.NewRequest(http.MethodGet, "/posts/abc", nil)
req.Header.Set("Accept", "application/json")
rec := httptest.NewRecorder()
h.ServeHTTP(rec, req)

// 404 application/problem+json: a non-numeric id names no resource
if rec.Code != http.StatusNotFound || rec.Header().Get("Content-Type") != "application/problem+json" {
	t.Fatalf("got %d %s", rec.Code, rec.Header().Get("Content-Type"))
}
```

## Booting the app in tests

Inject configuration instead of touching the process environment, and serve on port `0`:

```go
func TestApp(t *testing.T) {
	src := config.MapSource(map[string]string{"APP_KEY": config.GenerateKey(), "APP_ENV": "test"})

	app, err := lumek.New(lumek.WithSource(src), lumek.WithKind(lumek.KindTest), lumek.WithLogOutput(io.Discard))
	if err != nil {
		t.Fatal(err)
	}

	ready := make(chan string, 1)
	srv := lumek.NewHTTPServer("127.0.0.1:0", handler)
	srv.Ready = ready
	app.AddRunner("http", srv)

	ctx, cancel := context.WithCancel(t.Context())
	done := make(chan error, 1)
	go func() { done <- app.Run(ctx) }()

	addr := <-ready
	resp, err := http.Get("http://" + addr + "/")
	if err != nil {
		t.Fatal(err)
	}
	resp.Body.Close()
	// …assertions on resp.StatusCode…

	cancel()
	if err := <-done; err != nil {
		t.Fatal(err)
	}
}
```

Time-dependent code is tested with `testing/synctest` instead of sleeps.

## Fluent test client

<Callout type="warning">
Planned for the Prototype release: the `testing` package (imported as `lumektest`) boots the app with `APP_ENV=test` and in-memory SQLite, and runs requests in-process.
</Callout>

```go
func TestCreatePost(t *testing.T) {
	app := lumektest.New(t, bootstrap.New)

	app.Test(t).
		PostForm("/posts", url.Values{"title": {"Hello"}, "body": {"World"}}).
		AssertRedirectRoute("posts.index").
		AssertSessionHas("success")

	app.Test(t).PostJSON("/api/v1/posts", map[string]any{}).
		AssertProblem(422).
		AssertJSONValidationErrors("title")
}
```

| Group | Methods |
| --- | --- |
| Requests | `Get`, `Post`, `PostJSON`, `PostForm`, `Put`, `Patch`, `Delete`, `WithHeader`, `WithCookie`, `ActingAs`, `HTMX()` |
| Status | `AssertOK`, `AssertCreated`, `AssertNoContent`, `AssertStatus(n)`, `AssertNotFound`, `AssertUnprocessable` |
| Body | `AssertSee`, `AssertJSON`, `AssertJSONPath`, `AssertHeader` |
| Session | `AssertSessionHas`, `AssertSessionHasErrors` |

Database helpers (`AssertDatabaseHas`, factories) follow with the ORM.
