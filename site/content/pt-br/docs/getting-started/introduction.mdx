O Vukem é um framework web para **APIs REST e aplicações full-stack**: rotas, validação, um ORM com migrations, autenticação, recursos JSON com erros no formato problem+json, views com HTMX em primeiro lugar ou Inertia com React, Vue ou Svelte, GraphQL, gRPC e canais em tempo real, tudo controlado por uma única CLI.

## Por que o Vukem

- **Biblioteca padrão em primeiro lugar.** Handlers e middlewares são `net/http` puro. Qualquer `http.Handler` funciona.
- **Sem mágica.** Sem variáveis globais, sem registro via `init()`, sem injeção de dependência baseada em reflection. Os geradores escrevem código que é seu.
- **Tipado de ponta a ponta.** Structs de configuração tipadas, rotas nomeadas verificadas na inicialização e schemas no estilo Zod (`z`) que convertem toda entrada em tipos Go.
- **Tudo incluído, mas opcional.** SQLite já vem pronto; PostgreSQL, MySQL, Redis, MongoDB, S3 e WebSockets são módulos de driver separados, então você só baixa o que usa.
- **APIs como cidadãs de primeira classe.** Problem details da RFC 9457, grupos de rotas só com JSON, CORS e limite de tamanho do corpo já vêm embutidos.
- **Seguro por padrão.** Cabeçalhos de segurança com nonces de CSP, CORS que nega tudo por padrão, arquivos estáticos protegidos contra path traversal e verificações na inicialização que falham de forma segura, tudo mapeado para o [OWASP Top 10:2025](/docs/security/overview).

## Um gostinho

Um handler é uma função que recebe um `*web.Ctx` e retorna um `error`. Os erros retornados vão para um handler central, que gera a resposta certa para cada cliente.

```go title="routes.go"
func Routes(r *router.Router, posts *controllers.PostController) {
	r.Get("/", func(c *web.Ctx) error {
		return c.String(http.StatusOK, "Hello from Vukem")
	}).Name("home")

	r.Group("/admin", func(g *router.Group) {
		g.Resource("posts", posts) // posts.index, posts.store, posts.show…
	}).Name("admin.")
}

func (p *PostController) Show(c *web.Ctx) error {
	id, err := c.ParamInt("post") // id não numérico → 404
	if err != nil {
		return err
	}

	post, ok := p.store.Find(id)
	if !ok {
		return errs.ErrNotFound // página HTML ou problem+json, conforme a negociação de conteúdo
	}

	return c.JSON(http.StatusOK, post)
}
```
